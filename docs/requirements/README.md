# Product Requirements

Dieses Verzeichnis enthält die konzeptionelle Basis für StudyNexus. Es definiert, was wir bauen und für wen wir es bauen.

## 📄 Kerndokumente

* **[use-cases.md](use-cases.md)**: User Stories und funktionale Anforderungen aus Sicht der Studierenden.
* **[admin-po-use-cases.md](admin-po-use-cases.md)**: Detaillierte Spezifikation des Admin-Panels (inklusive Use Cases aus allen Sprints 0–12).
* **[domain-model.md](domain-model.md)**: Beschreibung der wesentlichen Datenentitäten (z.B. User, Module, Program) und deren Relationen.
* **[nfas.md](nfas.md)**: Non-Functional Requirements (Performance, Security, Skalierbarkeit, Mobile-First).

> **Tipp für Entwickler:** Wenn unklar ist, *warum* eine Funktion existiert oder wie sie aussehen soll, findest du die Antwort in diesen Requirements-Dokumenten.
